# Linux Desktop Messaging Client

An independent Electron-based desktop client
for accessing WhatsApp Web on Linux.

## Features

- Desktop application for Ubuntu and Debian
- Electron sandbox enabled
- Separate application profile
- Direct conversation opening through supported URLs
- Sharing links and text from external applications
- Integration with xdg-open
- HTTPS link handler
- Desktop notifications
